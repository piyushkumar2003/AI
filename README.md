# AI Engineering & Generative AI Projects

A curated collection of hands-on AI, Generative AI, Retrieval-Augmented Generation (RAG), and backend API projects built with Python, Jupyter Notebooks, LangChain, and FastAPI.

## 📂 Repository Structure

| Directory | Description |
| :--- | :--- |
| **`FastAPI/`** | REST APIs and backend services built with FastAPI to serve AI models and pipelines. |
| **`LangChain/`** | Experiments, chains, prompt templates, and agent workflows built using LangChain. |
| **`LangSmith/`** | Tracing, debugging, evaluation, and observability setups for LLM applications. |
| **`OpenAI/`** | Direct integrations, function calling, and API implementations using OpenAI models. |
| **`RAG/`** | Core Retrieval-Augmented Generation pipelines, document chunking, embeddings, and vector search implementations. |
| **`YT-RAG/`** | A YouTube Transcript RAG application that extracts video transcripts, embeds chunks, and enables interactive Q&A over video content. |
| **`SocialMediaProject/`** | End-to-end AI-powered application tailored for social media workflows and automation. |
| **`data/`** | Sample datasets, documents, and reference files used across notebooks and scripts. |

## 🛠️ Tech Stack

* **Languages:** Python, Jupyter Notebook
* **LLM Orchestration & Observability:** LangChain, LangSmith
* **Backend & APIs:** FastAPI
* **AI & Vector Search:** OpenAI API, Embeddings, Vector Stores (FAISS / Chroma)
